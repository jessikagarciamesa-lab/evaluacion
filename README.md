## Publicar en GitHub Pages

1. Entra a GitHub y crea un repositorio nuevo, por ejemplo `evaluacion-saberes`.
2. Pulsa **Add file → Upload files** y sube `index.html`, `robots.txt` y este `README.md`.
3. Ve a **Settings → Pages**. En *Source* elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`. Guarda.
4. En uno o dos minutos la herramienta estará en `https://<tu-usuario>.github.io/evaluacion-saberes/`.

## Primer ingreso

- La primera vez que abras el enlace en un dispositivo, crea tu **usuario y contraseña**.
- Todas las evaluaciones se guardan **cifradas (AES-256)** únicamente en ese navegador. Nada se envía a GitHub ni a ningún servidor.
- **La contraseña no se puede recuperar.** Si la olvidas, la información no se puede abrir.

## Respaldo y cambio de dispositivo

- Usa el botón **💾 Respaldo** con frecuencia. Descarga un archivo cifrado con todas las evaluaciones.
- Para seguir en otro computador o tablet: abre el enlace, elige **Importar respaldo** y entra con el mismo usuario y contraseña.
- Borrar los datos de navegación del navegador borra las evaluaciones guardadas en él.

## Seguridad: lo que hay que saber

- El enlace de GitHub Pages es público: cualquiera puede ver la pantalla de ingreso y el código de la herramienta (las preguntas y las tareas), pero **no** los datos de los estudiantes, que solo existen cifrados en tu dispositivo.
- Si quieres que el código tampoco sea visible, el repositorio debe ser privado; GitHub Pages con repositorio privado requiere un plan pago de GitHub.
- La sesión se cierra sola tras 20 minutos sin uso.
